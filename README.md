# خطوات التشغيل

1. **Firebase Console** → Project settings → Add app → Android → اسم الباكدج: `com.mohamed.educenter`
   نزّل ملف **google-services.json** وحطه في root الريبو (جنب `pubspec.yaml`) — `tool/patch_manifest.py` بيركّبه لوحده وقت البيلد.
   (من غير الملف ده الإشعارات والتطبيق مقفول مش هتشتغل خالص.)
2. ارفع الفولدر ده كله على GitHub (repo جديد للتطبيق) واربطه بـ Codemagic — هيقرا `codemagic.yaml` لوحده.
3. ارفع `assets/index.html` (نفس الملف) كمان على repo الموقع (GitHub Pages) عشان النسخة الأونلاين تبقى محدثة.
4. للـ Push والتطبيق مقفول: من فولدر المشروع شغّل
   `npm i -g firebase-tools && firebase login && cd functions && npm i && cd .. && firebase deploy --only functions`
   (محتاج خطة Blaze).
5. Realtime Database Rules — ضيف:
   `"fcmTokens": { "$key": { ".read": false, ".write": "auth != null" } }`
   وتأكد إن المستخدم يقدر يكتب `seen` على رسايل `chats` / `parentChats`، والمدرس يقدر يحذف منهم ومن `chatAudio`.

## اللي اتعدّل في النسخة دي
- **اللوجو (Dr.Math):** أيقونة التطبيق بكل المقاسات (عادية + دايرية + Adaptive لأندرويد 8+) + أيقونة الإشعار (أبيض) + أيقونة تبويب المتصفح في `index.html`. الصور في `tool/icons/` و`tool/patch_manifest.py` بينسخها لوحده وقت البيلد.
- **صوت الإشعار:** قناة إشعارات `edu_high` أهمية عالية بصوت الموبايل الافتراضي + اهتزاز، والإشعار بيوصل والتطبيق مقفول (بعد نشر الـ Function). والتطبيق مفتوح بيشغّل صوت الإشعار الافتراضي بتاع الموبايل بدل الـ beep.
- **الصلاحيات:** بيطلب أول فتح: إشعارات، مايك، كاميرا، صور، فيديوهات. والمايك/الكاميرا بيتطلبوا برضه وقت الاستخدام (تسجيل صوت، تصوير واجب، مسح QR).
- **مهم:** لازم تعيد رفع `assets/index.html` على GitHub Pages، وتعيد نشر الـ Functions: `firebase deploy --only functions`.
- **شريط الحالة وشريط التنقل:** بياخدوا لون الصفحة الحقيقي (لايت/دارك + السمة: الأساسي/أزرق/زمردي) وبيتغيروا لوحدهم لما تبدّل السمة أو الشاشة، والأيقونات بتتحول فاتحة/غامقة حسب اللون.
- **شريط الحالة (تحديث):** شاشة "جاري تحميل التطبيق" بقت بلون السمة (كانت كريمي ثابت)، والشريط بيبدأ من أول لحظة بنفس لون السمة، والتطبيق بيحفظ آخر لون ويفتح بيه (مفيش وميض أبيض)، والتحديث عند تبديل السمة بقى فوري. اتضاف `shared_preferences` في `pubspec.yaml`.

## إصلاح الإشعارات (التطبيق مقفول) + التهنيج
- **Function:** كانت بتمسح كل توكنات الأجهزة عند أي `invalid-argument`، فالإشعارات كانت تقف نهائيًا بعد أول خطأ. دلوقتي بتمسح بس التوكن الميت فعلًا، وبتسجّل كل نتيجة في اللوج. **لازم تعيد النشر:** `firebase deploy --only functions`
- **التطبيق:** طلب صلاحية الإشعارات كان بيتعارض مع طلبات الصلاحيات التانية → دلوقتي بالترتيب ومرة واحدة. التوكن بيتجاب الأول مع إعادة محاولة، وبيطلب استثناء من توفير البطارية مرة واحدة (مهم لشاومي/سامسونج/أوبو).
- **الصفحة:** توكن الجهاز مبقاش بيتمسح عند إعادة الاشتراك الداخلي. وتهنيج: فحص لون الشريط كان كل 300ms ومع كل transition/animation → بقى مجمّع وكل 1.5 ثانية، وتحديث قوائم الشات اتجمّع. **ارفع `assets/index.html` الجديد على GitHub Pages.**

### لو الإشعارات لسه مش بتوصل، افحص بالترتيب
1. `firebase functions:log` — لازم تشوف `push sent` أو `no fcm tokens for recipient` بعد ما حد يبعت رسالة. لو مفيش أي سطر: الـ Function مش منشورة (محتاج Blaze) أو اسم الـ instance غلط.
2. Realtime Database ← `fcmTokens/<المستلم>/<توكن>`: لو فاضي → سجّل خروج ودخول من التطبيق نفسه (مش المتصفح)، وتأكد إن `google-services.json` اتحط وقت البيلد (Codemagic log: مفيش WARNING).
3. إعدادات الموبايل ← التطبيق ← الإشعارات = مفعّلة، والبطارية = "بدون قيود". والتطبيق مش عامله "إيقاف إجباري".
